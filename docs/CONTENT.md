# Content & balance workflow

Everything the player sees is data under `src/data/`. Simulation code in `src/simulation/` is generic and never contains content-specific numbers. No backend is involved: edit data, run tests, build, deploy.

## 1. Adding content

| What | File | Notes |
| --- | --- | --- |
| Activity / job | `data/activities/index.ts` | `legit()` or `risky()` helper. Set `district`, `requirements`, `reward`, `xp`, `skillScaling`, `equipmentScaling`, `idle`/`offline` flags and outcome texts. It appears automatically in the Jobs screen and in any building whose `jobs` action matches the category. |
| Skill perk | `data/skills/index.ts` | Add a `PerkDef` with `modifiers`. Perks unlock automatically at `level`. Any `ModifierKey` from `types/game.ts` works everywhere. |
| Item / upgrade | `data/items/index.ts` | Category decides the equipment slot. Add the id to a shop in `data/districts/index.ts` (`SHOPS`). |
| NPC + dialogue | `data/npcs/index.ts` | Add an `NpcDef` and a `DialogueDef`. `entries` are evaluated in order; the first whose requirements pass is the entry node. Choices carry `effects`/`requirements`. Place the NPC in a district map (`map.npcs`) or an interior. |
| Quest | `data/quests/index.ts` | Stages are `Condition`s evaluated after every change (`evaluateQuests`). `autoStart: true` starts it when requirements are met; otherwise start it from a dialogue `startQuest` effect. |
| District | `data/districts/index.ts` | Add a `DistrictDef` with `requirements`, prices and a `map` (tile coordinates: roads 3 tiles wide, buildings in the blocks between them, door at the bottom-centre). Add the id to the `DistrictId` union in `types/game.ts` and the schema enum in `schemas/save.ts`. The content test checks overlaps. |
| Interior | `data/districts/index.ts` (`INTERIORS`) | Floor, walls and props with actions; link it from a building `enter` action. |
| Business / property / vehicle / investment asset | `data/businesses/index.ts` | Property `tier`, vehicle `tier` and modifiers feed requirements and bonuses. |
| Crew archetype, work type, training program, facility | `data/crew/index.ts` | `requirements` gate who appears in the recruit pool; `minSharePct` is the lowest contract they accept. |
| Random event | `data/events/index.ts` | `weight`, `requirements`, `choices` with effects; `offlineDefault` is the choice applied while away. |
| Achievement | `data/achievements.ts` | A `Condition` plus optional reward effects. |
| Background | `data/backgrounds.ts` | Needs a matching `q_intro_<id>` quest. |
| Ad placement | `schemas/ads.ts` (`AD_PLACEMENTS`) + render it with `<AdSlot placement="…">` | Placements are an explicit allowlist. |

Requirements, conditions and effects are small data unions (`Requirement`, `Condition`, `Effect` in `types/game.ts` and `data/types.ts`). Adding a new kind means extending the union and the switch in `simulation/requirements.ts`, `simulation/progression/quests.ts` or `simulation/effects.ts`.

## 2. Adjusting balance

`src/data/balance.ts` holds every tunable: starting cash, day length (20 real minutes), energy, offline caps (8h base, 48h hard cap), XP curve, activity slots and risk/heat numbers, business growth, HK capacities/costs/tiers/morale/loyalty, investment ticks, event cadence, prestige thresholds. Per-content numbers (rewards, durations, prices, costs) live next to the content. After changing numbers run `npm test` — the economy and idle suites assert invariants rather than exact values, so they catch regressions such as rewards before completion or duplicate income.

Rule of thumb used in the shipped numbers: starter jobs pay ₦1–3k per 1.5–3 minutes; a tier-2 phone (₦45k) is reachable in the first session; the first business (₦180k) is a mid-first-hour goal; the HK unlock needs ₦150k plus Management 4; districts scale prices ×1 → ×2.2.

## 3. Save compatibility

- Bump `SAVE_VERSION` in `data/version.ts` when the **shape** of `GameState` changes, add a migration in `persistence/migrations.ts` (keyed by the version it upgrades from) and extend `schemas/save.ts`. Add a test in `tests/unit/persistence.test.ts`.
- Bump `CONTENT_VERSION` when content changes in a way saves should notice. Removed ids are reconciled automatically (`reconcileContent`): unknown items, activities, quests, businesses, crew defs and assignments are dropped with a note instead of breaking the save.

## 4. Map assets

There are no binary art assets. Tiles (`game/world/tileset.ts`), characters and props (`game/world/sprites.ts`) are char-art rows rasterised at boot. To add a prop: add a `PropArt` entry in `PROPS` (rows + palette + collision body) and reference its `kind` from a district map. To add a building palette: append to `BUILDING_PALETTES`. Icons and demo ad images are generated by `npm run icons`.

## 5. Testing

```bash
npm test                 # unit (fast)
npm run build && npm run test:e2e   # end-to-end against the static export
```
